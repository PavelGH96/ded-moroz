# Дед Мороз заходил

Лендинг: именное письмо и видео от Деда Мороза к Новому году.

- `index.html` — весь сайт одним файлом (анкета, таймер до Нового года по Москве, 3D-Дед Мороз).
- `ded-*.webp`, `ded-moroz-depth.png` — слои и карта глубины для объёмного Деда Мороза.
- `supabase/functions/dm-order/` — приём заявок: сохраняет в базу, собирает PDF-письмо и шлёт всё в Telegram.

## Как устроен приём заявок

Форма отправляет заявку на `https://tribgnfjiiwmiktzjeyy.supabase.co/functions/v1/dm-order`.
Функция пишет её в таблицу `dedmoroz.orders` (проект Supabase WiseWallet, отдельная схема),
собирает PDF-письмо и отправляет в Telegram текст заявки, PDF и фото.

Секреты функции (Supabase → Edge Functions → Secrets):

| Секрет | Обязателен | Что это |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | да | токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | нет | куда слать заявки; если не задан, берётся чат, где боту первым написали `/start` |
| `ALLOWED_ORIGINS` | нет | домены сайта через запятую, например `https://dedmoroz.ru` |

Персональные данные в базе обезличиваются через 90 дней (задача pg_cron `dedmoroz-anonymize`).
